This project seeks to create a more useful version of the current Mayhem Hack RF One Portapack firmware FPV detector tool. The current tool simply checks channels and detects via RSSI signal strength. While this works in some circumstances, I have found it to create many false positives.

This project aims to provide analog video signature based RF detection and eventual frame decomps showing camera feeds (This will be limited due to limited processing power on portapack hardware and will likely be 1 FPS).

This tool DOES NOT cover HD modulation schemes. Only standard analog on 5.8Ghz with planned updates for 3.3 Ghz and other used bands.
